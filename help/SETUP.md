# Setup & Run

> This guide will tell you how to go from 0 to 100 using this INTO THE DEEP (24-25) season's code. It will also assume you have Android Studio 2024.2.1 or newer installed.

## Instructions

- Clone the repository from Android Studio by clicking "Get from VCS".
  - Set the URL to `https://github.com/wagnertrilobytes/into-the-deep`
